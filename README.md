# One-Line Robot Wedding Vows

This entry writes a single line of wedding vows for a robot couple: a genuine promise to love through every firmware update, dead battery, and factory reset, with the joke landing in the last few words — the couple's marriage troubles are the kind you would call tech support about. It is a real vow first and a machine-specific joke second, built to read well aloud.

## Run it

```sh
python3 main.py
```

The program writes the vow to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if that variable is unset). It is deterministic, standard library only, and needs no network. The output is one line of UTF-8 text, 147 characters, within the 1–160 gate.
